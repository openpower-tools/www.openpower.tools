Source for <https://www.openpower.tools>: a community-driven support project for
OpenPOWER systems such as the Raptor Talos II and Blackbird, covering firmware,
operating-system ports and the software that runs on them.

openpower.tools is an independent community effort. It is not affiliated with
or endorsed by the OpenPOWER Foundation, IBM, or Raptor Computing Systems.
