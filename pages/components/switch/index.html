A native checkbox drawn as a switch, for settings that take effect immediately. The control keeps checkbox semantics for assistive tech. The thumb itself carries the state as the IEC power numeral - 1 on, 0 off - and hovering plays a slow, repeated preview behind the thumb: a dimmed ghost slides to the state a click would set - what would be, not what is.
