A numbered procedure. Steps are a regular ordered list; a data-state attribute marks steps done, current or error, colouring the number bubble with the status tokens while the wording carries the meaning.

Example

  1. Back up the current PNOR. Read the flash to a file with pflash before touching anything.
  2. Verify the new image. Check the sha256 against the release notes.
  3. Flash the image. Write the new PNOR from the BMC and wait for completion.
  4. Reboot and confirm. Watch the serial console for the new firmware banner.

With an error

  1. Verify the image. The sha256 matches.
  2. Flash failed. The write stopped at 40%; do not power off - retry it.

Markup

<op-steps>
  <ol>
    <li data-state="done">Back up the current PNOR.</li>
    <li data-state="current">Flash the image.</li>
  </ol>
</op-steps>
