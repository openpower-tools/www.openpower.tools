Label/value pairs for hardware specs, firmware versions and other metadata. The definition list is regular light-DOM markup; the element lays it out on a grid.

Example

Mainboard
Talos II Lite (T2P9S01)
CPU
POWER9 Sforza, 8 cores, DD2.3
BMC
ASpeed AST2500 running OpenBMC
Host firmware
Hostboot, Skiboot, Petitboot
PNOR
128 Mbit SPI flash

Markup

<op-key-value>
  <dl>
    <dt>CPU</dt><dd>POWER9 Sforza, 8 cores</dd>
  </dl>
</op-key-value>
