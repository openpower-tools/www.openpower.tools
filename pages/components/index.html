Every web component the site is built from, shown with its states and variants so their look can be planned before content lands. Each entry links to a page with the full set.

Every component type the site plans to build with is now here, including the A-Frame scene integration; refinements land as the content pages start using them.

Content

  • Callout: highlighted notes, tips and warnings
  • Badge: compact status markers
  • Card: titled content containers
  • Details: collapsible sections
  • Key-value: label/value pairs for specs and metadata
  • Table: tabular data in a scrollable frame
  • Source: labelled code blocks with a copy control
  • Timeline: dated events with status dots
  • Empty state: placeholders for absent content
  • KPI: single measurements, data-forward
  • Steps: numbered procedures with states
  • Tree: collapsible hierarchies

Controls

  • Button: actions with primary and danger weights
  • Input: labelled text entry
  • Select: labelled native selects
  • Checkbox: native checkboxes
  • Switch: immediate on/off settings
  • Tooltip: hover and focus annotations
  • Chip: interactive filter tokens
  • Progress: determinate and indeterminate bars

Navigation

  • Tabs: tabbed regions with keyboard activation
  • Breadcrumb: where-am-I trails
  • Pagination: page navigation for split lists

Immersive

  • Scene: embedded A-Frame scenes with Rust-driven behaviour
