A tabbed region: the panels are light-DOM op-tab children and the tablist is rendered from their labels, activated by click or the arrow keys.

Example

Install from the ppc64el netinst image; the installer runs under Petitboot's kernel and picks up the NVMe target directly.

Fedora Server for ppc64le boots unmodified; select the HTTPS install source from the Petitboot menu.

Community images exist for POWER9; serial console settings need adjusting before first boot.
