A collapsible hierarchy for partition layouts and device trees. Branches are native details and summary pairs, so collapsing works without wasm and stays keyboard-accessible; leaves are plain list items.

Example

  • PNOR flash layout
    • HBB Hostboot base, 512 KiB
    • HBI Hostboot extended image
    • PAYLOAD Skiboot
      • skiboot.lid OPAL runtime services
    • BOOTKERNFW Petitboot kernel, 16 MiB

Markup

<op-tree>
  <ul>
    <li><details open><summary>PNOR</summary>
      <ul><li><code>HBB</code> 512 KiB</li></ul>
    </details></li>
  </ul>
</op-tree>
